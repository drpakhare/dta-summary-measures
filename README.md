# Data Extraction and Summary Measures for Diagnostic Accuracy Studies

A 30-minute session for MetaMastery 3.0, a skill-building workshop on systematic review and meta-analysis at AIIMS Bhopal. It follows one illustrative review, CRP for serious bacterial infection in febrile infants, through the 2×2 table and the summary measures of diagnostic accuracy.

## Session objectives

By the end of the session, participants will be able to:

1. Set up a 2×2 table from a diagnostic accuracy study, with the index test in the rows and the reference standard in the columns.
2. Calculate and interpret sensitivity, specificity, predictive values, likelihood ratios and the diagnostic odds ratio, with confidence intervals.
3. Explain why predictive values change with prevalence and should not be pooled across studies.
4. Use likelihood ratios to move from pre-test to post-test probability.
5. Explain ROC curves, the area under the curve and the threshold effect, and why sensitivity and specificity must be pooled jointly.
6. Rebuild a 2×2 table from the figures a paper reports, and check it.
7. Make and record extraction decisions on inconclusive results, unverified participants, multiple cut-offs and units of analysis, in line with QUADAS-3.

All study data in this repository are illustrative, constructed for teaching.
